# Minecraft Crossplay

## [Pumpkin](pumpkin)

[Pumpkin](https://pumpkinmc.org/)
Minecraft server written in Rust with native Java and experimental Bedrock support. **Pumpkin is under heavy development. Expect incomplete features and bugs.**

## [Purpur-GeyserMC-Floodgate](purpur-geysermc-floodgate)

[Purpur-GeyserMC-Floodgate](https://purpurmc.org/)
Drop-in replacement for Paper servers designed for configurability, and new fun and exciting gameplay features, with the addition of GeyserMC and Floodgate
