# Youer

NeoForge hybrid server implementing the Paper/Purpur API. Supports NeoForge mods + Bukkit/Spigot/Paper plugins.

Check out the [MohistMC Website](https://mohistmc.com/) for more information.

## Server Ports

The minecraft server requires a single port for access (default 25565) but plugins may require extra ports to enabled for the server.

| Port  | default |
|-------|---------|
| Game  | 25565   |
