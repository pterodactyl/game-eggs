# WitcherOnline 
![witcheronline](https://staticdelivery.nexusmods.com/mods/952/images/11590/11590-1767947173-1646630618.png)

## Description
Play The Witcher 3: Wild Hunt multiplayer with friends. Play Gwent with other players. Complete quests and explore the world.
Using the mod from [Nexus](https://www.nexusmods.com/witcher3/mods/11590)

> [!IMPORTANT]
> A non-pirated copy of the latest version of Next Gen, Steam or GOG version 4.04+ is required (Clients only). 

## Server Ports
Witcher Online uses ports as shown below 
|Port    |Default  |
|--------|---------|
|Game UDP    | 4000    |

## Install Notes

| Requirements        | Memory| Storage | 
|---------------------|-------|---------|
| Minimal             | 1 GB   | 1 GB   |

There are 2 options to get server working
1. Using a Nexus premium account - Paste your key to the API field and let the installer download the files .

2. Manually upload the zip file - Create server and wait until server is accessible, manually upload the server file and hit reinstall server. 
After this the server should be working.

Server file can be found on [Nexus](https://www.nexusmods.com/witcher3/mods/11590?tab=files)

## Settings 

Location of server Files : / 

server.properties

Port will be written with the assigned port of the container.

## Clients
You can following the getting started guide : [Witcher Online Guide](https://rejuvenate.gitbook.io/witcheronline/guides/client-setup)

Clients need to change there `bin/WitcherOnline/config.xml` to change there name and IP/port to the correct server value's.
